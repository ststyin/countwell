## 回归原因

Vite 的静态资源响应带 `Vary: Origin`，预缓存请求没有 Origin，而 HTML 的 crossorigin module / CSS 请求可能带 Origin。原来的 `cache.match(request)` 因此无法命中离线资源。回归测试先复现两条失败，再验证修复；现在仅对白名单内同源公开应用资源忽略 Vary，API、JSON、查询参数和鉴权请求继续排除。
